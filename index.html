它为什么不会「活不过三天」

市面上的桌面宠物大多三分钟热度：太吵、太空、太贵。我们把「不打扰」当成可调参数来设计。

原则 01

不打扰

待机决策间隔 14~30 秒（原本 4~9 秒），散步权重降到 1/4，打盹权重升到 4 倍。它会长时间安静趴着，偶尔看你一眼，而不是在屏幕上疯跑。

原则 02

有内容

五维养成、4 地点探险、7 个小游戏、图鉴、5 章剧情、9 个天赋、8 件装扮 + 5 款皮肤、16 个成就 —— 每天都能发现一点新东西。

原则 03

真桌面

无边框悬浮、颜色键透明、四周点击穿透：它像桌面上的一张便利贴，不挡你干活。时钟 / 天气 / 网速挂件则真有用途。

技术实现

纯 Python 单文件，13,199 行；只依赖标准库 tkinter 与 Pillow。

透明窗口 + 点击穿透

tkinter 没有逐像素透明。做法是给窗口指定一个「绝不出现在素材里」的颜色当色键： -transparentcolor 会把该颜色当透明，而且该像素区域连鼠标都能穿透。

KEY_COLOR = "#ff00fe"
root.wm_attributes("-transparentcolor", KEY_COLOR)
canvas.configure(bg=KEY_COLOR)
# 色键像素 → 透明 + 可点透
# 蛙身像素 → 正常响应点击

素材管线 + 程序化呼吸动画

15 张 webp/gif 逐张过管线：四角色差抠背景 → 按「脚底线」对齐 → 磁盘缓存（二次启动 < 100ms）。 只有 1 张静态待机图，用正弦缩放 + 轻微位移程序化生成 6 帧呼吸动画，0 额外美术资源。

状态机与权重表

40ms tick 驱动五维数值（饥饿/心情/精力/亲密度/无聊），每轮按权重抽动作：打盹 4 / 发呆 2 / 散步 1 / 自言自语 1。 陪伴感来自「它还在」，不是「它在闹」。

AI 对话 + 本地记忆库

OpenAI 兼容协议，可切千问 / DeepSeek / Kimi / 智谱 / 本地 Ollama。 对话后抽取结构化记忆（姓名、生日、喜好）写进存档，下次注入 system prompt —— 所以它记得你的生日。

三步跑起来

Windows 10/11（64 位）+ Python 3.10~3.14。只有一个第三方依赖：Pillow。

  1. 拿到代码 git clone <本仓库地址>，或直接下载 ZIP 解压。
  2. 安装依赖 pip install pillow
    离线环境可用仓库 Release 中的「离线安装包」，内置各版本 wheel + pip，全程不联网。
  3. 启动 python desktop_pet.py
    Windows 也可直接双击 启动桌宠.bat：它会自动找 Python、缺 Pillow 自动装、出错会停下来显示原因。

自检（可选）

python 检查素材.py            # 素材是否齐全、有没有误用外部副本的图
python desktop_pet.py --selftest
python selftest_features.py   # 18 阶段功能自检 → 预期输出「结论：全部通过」
