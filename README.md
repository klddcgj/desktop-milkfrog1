## 一、30 秒跑起来

### 方式 A：双击启动（推荐，Windows）

| 双击这个文件 | 效果 |
|---|---|
| **`启动桌宠.bat`** | 直接启动桌宠。会自动找可用的 Python、缺 Pillow 自动安装；**任何错误都会停下来显示原因，不会一闪而过** |
| **`调试启动.bat`** | 保留控制台 + 先跑素材自检 + 实时打印状态机日志（排障、答辩讲解用） |

> 启动器做了三件防坑的事：
> ① 自动避开 Microsoft Store 的假 `python` 存根（会先 `python -c "import sys"` 试跑，失败就换 `py -3`）；
> ② 先 `chcp 65001`，解决中文 Windows 默认代码页 936 导致的中文乱码；
> ③ 出错必 `pause`，绝不闪退。

### 方式 B：命令行

```bash
pip install pillow          # 唯一依赖（tkinter 是 Python 自带）
python desktop_pet.py       # 启动桌宠
```

| 命令 | 作用 |
|---|---|
| `python desktop_pet.py` | 启动桌宠 |
| `python desktop_pet.py --selftest` | 只做素材管线自检，不开窗口（现场排障用） |
| `python desktop_pet.py --verbose` | 控制台实时打印状态机日志（答辩讲解用） |
| `python desktop_pet.py --height 200` | 改宠物大小 |
| `python desktop_pet.py --pos 100,600` | 指定初始位置 |
| `python desktop_pet.py --llm-test "你好"` | 只测大模型接口连通性，不开窗口 |

> 启动后宠物**不会抢走你的键盘焦点**（窗口带 `WS_EX_NOACTIVATE`，点它也不会打断你正在打字的窗口），
> 也不会出现在任务栏 / Alt-Tab 里。退出：右键宠物 → 退出，或关掉那个控制台窗口。

**四维状态**：心情 / 饱食 / 精力 / 无聊，随时间自动衰减，驱动情绪、动画与台词。

### 身体状况与进阶互动（第二阶段）

| 机制 | 触发条件 | 表现 |
|---|---|---|
| **强制睡眠** | 精力 = 0 | 自动睡着，冒「累到断电了…zzZ」 |
| **再睡倒计时** | 被叫醒后 5 秒内没有任何互动 | 自己又睡回去，冒「不行了…我又要睡着了…」 |
| **叫醒抱怨** | 睡觉时点它 | 「唔…干嘛呀，我正睡着呢…」等抱怨文案 |
| **好感度/心情表情** | 心情 ≥95 / ≤50 / ≤20 / =0 | 依次切素材2 / 素材3 / 素材6 / 素材5 |
| **伤感文案 + 点击刷新** | 心情 ≤20（或归零） | 自动循环播伤感短句；**这时点它会换下一句**，而不是变开心 |
| **饿坏** | 饱食 = 0 | 切素材11 + 「咕噜噜…我饿坏了，快给我吃的！」 |
| **生病** | 饱食 = 0 直接病倒；饱食在 38~62 区间每 18 秒掷一次骰子（20% 概率） | 切素材8，状态掉得更快，**只能靠右键「治疗」痊愈** |
| **手动治疗** | 右键 → 治疗（生病时才有效） | 「谢谢你照顾我！舒服多啦～」，心情 +15 |
| **讲个笑话** | 右键 → 讲个笑话 | 切素材4 + 一句冷笑话，心情 +8 |
| **全状态归零** | 心情/饱食/精力都见底且无聊极低 | 切素材9（祈祷蛙），会**锁存**直到你把它救回来 |
| **睡觉动画切换** | 睡觉时点它**第 1 下**换姿势（素材7 ↔ 原睡姿），**第 2 下**叫醒 | 「（翻了个身…）」 |
| **AI 聊天节奏** | 平时正常聊天；**偶尔**才主动讲一个笑话 | 三重节流：先正常聊满 8 句 + 距上次笑话 ≥5 分钟 + 7% 概率（实测 60 句里约 1 次） |

> 想现场演示某个状态不用干等：`python desktop_pet.py --stats happy=0` 或
> `--stats happy=0,full=0,energy=0,bored=0`，也可以直接 `--sick` 让它生病。

### 休闲小游戏 + 探险挂机 + 数值平衡（第七阶段）

**目标：一天开 2~3 次就够，不用一直盯着。**

#### 🎮 4 个小游戏（右键 →「玩个小游戏」）

| 游戏 | 玩法 | 奖品 |
|---|---|---|
| ✊ 猜拳大作战 | 三局两胜，每局 3 秒冷却 | 赢：好感+8 金币+10 经验+15；输也有陪伴奖 |
| ⭐ 接星星 | 60 秒，← → 或 A/D 控制，⭐+10 ☄️-5 🌟+50 | ≥30 分好感+15 金币+20，20% 掉稀有 |
| 🃏 记忆翻牌 | 12 张牌找 6 对，步数越少奖励越高 | ≤10 步：好感+20 金币+25 必掉稀有 |
| 🐸 打地鼠 | 30 秒点冒头的奶蛙 | ≥15 次：好感+18 金币+22，掉稀有 |

- **每天每个游戏 5 次**（`CFG.GAME_DAILY_LIMIT`），窗口右上角显示剩余次数，跨天自动重置
- 玩游戏时奶蛙会**趴着陪你看**，精力消耗减半
- 吃「幸运饼干」→ **当天所有游戏奖励 x2**
- 奖励走统一入口 `PetStats.add_reward(coins, exp, bond, items)`，一处结算全局生效
- 所有定时任务登记在 `self.jobs`，**关窗立刻取消**，不留后台循环；星星用 12 个对象池复用图元

#### 🗺️ 探险挂机化

- 每个地点新增 **4 个时长档位**：短途 30s / 中途 10min / 长途 1h / **过夜 8h**（精力消耗按时长放大）
- **离线也计时**：探险存的是「结束时间戳」而不是剩余秒数，关掉程序再打开，到点了直接弹结算把收益发给你；没到点提示「还剩 X 小时 X 分」
- **离线收益封顶 8 小时**，出门期间饱食/心情衰减几乎停滞
- 新道具「**探险指南针**」：下一次探险收益 x2，可与便当/手电筒等叠加
- **地点熟练度**（0~100）：每去一次 +5，满 100 后该地点掉落整体升档
  （实测：common 70% → 60%，史诗 8.6% → 11.2%，传说 2.1% → 2.7%），进度条显示在选择窗口里

### 喂食与赠送（物品化改造）

**喂食不再凭空发生**：右键「喂食」打开「吃背包里的食物」面板，只列背包里的**食物**
（珍珠奶茶 / 草莓蛋糕 / 营养套餐），点「喂」才真的吃掉一个：

- 饱食 / 心情 按物品效果结算，同时 **好感 +2、金币 +2、经验 +12**
- 计入「投喂 N 次」每日任务 与 「美食家」成就（累计 50 次）
- 背包没食物 → 自动弹商店；太饱（≥88）→ 摇头拒绝；非食物 → 提示「可以送给奶蛙当礼物」

**赠送礼物**：右键「赠送礼物」打开赠送面板，每件物品直接标出**好感加成**：

| 规则 | 说明 |
|---|---|
| 好感值 | 物品自带 `gift_bond`，没有就按价格折算（≈价格的 22%，最低 +2） |
| 最爱加成 | 草莓蛋糕 / 音乐盒 / 野花 / 珍珠奶茶 / 逗猫棒 → **好感 ×1.6** + 专属台词 |
| 送出效果 | 好感 +N、心情 +6（最爱 +12）、无聊 -15、经验 +9 |
| 禁止赠送 | 藏宝图碎片 / 奶蛙之铃 / 松果帽子 / 鸭鸭明信片 / 便当 / 手电筒 / 指南针 / 雨伞 / 大背包 |
| 满级 | 好感 1000 后会劝你别再破费 |

> 训练闭环：喂食和送礼都要消耗物品 → 物品靠金币买或出门探险捡
> → 「赚钱 → 探险 → 投喂/送礼涨好感」形成真正的养成循环，而不是点鼠标数值就涨。

### 程序化呼吸待机动画（第九阶段）

**不用 AI 生图、不加外部素材**：纯用 C 级算子把现有 `idle` 图做「缩放 + 微旋转 + 上移」，
拼成 6 帧循环 → 看起来就是肚子一鼓一瘪在呼吸。

| 帧 | 缩放 | 上移 | 倾斜 | 说明 |
|---|---|---|---|---|
| 0 | 1.000 | 0 | 0° | 正常待机 |
| 1 | 1.015 | 1px | 0.5° | 吸气开始 |
| 2 | **1.030** | **2px** | 1.0° | 吸气最大（肚子鼓起来） |
| 3 | 1.015 | 1px | 0.5° | 呼气开始 |
| 4 | **0.990** | 0 | -0.5° | 呼气放松 |
| 5 | 1.000 | 0 | 0° | 回到原位 |

- 每帧 **400ms**，6 帧 = **2.4 秒**一个呼吸周期
- 6 帧拼进**同一尺寸画布**（取最大包围盒），切帧完全不跳
- 生成目标 `%TEMP%/desktop_pet_cache/idle_anim/`：`f000.png…f005.png` + `meta.json`
- **缓存键 = CACHE_VERSION + PET_HEIGHT + 参数表**；参数一改自动重建，否则 0.02 秒读缓存
- 实测：首次生成 **0.07 秒**，之后读缓存 **0.02 秒**，6 帧不透明像素 18407→19546→17967（确认在呼吸）

**待机小动作**（覆盖在呼吸循环上，每 8~15 秒随机一个，各 1.2 秒）：

| 小动作 | 实现 |
|---|---|
| 歪头 | tilt 0° → **8°** → 0°（sin 曲线） |
| 左右看 | 中段 flip 翻转（模拟转头看两边） |
| 抖一下 | x 偏移 ±3px 快速抖动 |
| 眨眼感 | dim 降到 **0.85** 短暂变暗（没有眼睛素材的替代方案） |

**状态机优先级**（严格遵守）：
`事件动画(happy/talk/eat/pat)` > `睡觉/生病/探险` > `待机呼吸动画 + 小动作`
- 事件动画播完自动回到呼吸
- 散步时呼吸动画 + bob 上下浮动叠加
- 睡觉仍用素材7、生病仍用 sick 素材，都不受影响

**阴影同步呼吸**：吸气帧阴影宽度 ×1.05 且变浅，呼气帧 ×0.97 且变深（Canvas 椭圆每帧调 bbox + 填充色）。

> 以后你有了正式待机 GIF：往 `assets/` 一丢，把 `ASSETS["idle_anim"]` 改成
> `dict(kind="gif", profile="white", names=["assets/pet_idle.gif"])` 就自动替换，代码不用动。

## 四、接入大模型 API Key（三种方式，任选其一）

默认使用**本地关键词规则**聊天，不联网也能完整演示。想让它真正会聊天，把 API Key 接上即可。
Key 只保存在本机 `config.json`（已在 `.gitignore` 里），**不会写进源码、不会上传**。

### 方式 A：图形向导（推荐，双击即可）

**双击 `配置API密钥.bat`** → 选厂商 → 粘贴 Key → 点「保存并测试」。

向导会真的发一句「你好」给模型验证连通性，并当场告诉你结果：

```
✅ 接入成功！
已写入：D:\黑客松\config.json
厂商：DeepSeek　模型：deepseek-chat
模型回复：你好呀！我是小黄团～
```

也可以从桌宠身上进：**右键宠物 →「配置 API Key」**（配好后重启桌宠生效）。
Key 输入框默认打码，想看内容勾一下「显示」即可。

### 方式 B：命令行（可脚本化）

```bash
python desktop_pet.py --set-llm-key sk-xxxxxxxx --llm-provider deepseek
```
它会写入 `config.json` 并自动测试连通性。加 `--no-test` 可只保存不测试。

### 方式 C：环境变量 / 手改配置文件

```bat
set DEEPSEEK_API_KEY=sk-xxxxxxxx                     :: Windows CMD
copy config.example.json config.json                 :: 或用记事本填 config.json 里的 api_key
```

启动时自动检测并开启。也可以手动控制：

```bash
python desktop_pet.py --llm on       # 强制开启
python desktop_pet.py --llm off      # 强制关闭（纯本地规则）
python desktop_pet.py --llm on --llm-provider ollama          # 用本地 Ollama，不需要 Key
python desktop_pet.py --llm-test "你好"                        # 只测接口，不开窗口
python desktop_pet.py --setup-llm                              # 打开图形向导
```

### 阿里云百炼（Token Plan）专用说明

百炼控制台给的新版 Key 是 `o1_` 开头的**混淆 Key**，默认还要你装一套 Node.js CLI（`irm ... | iex`）。
本程序**不需要那套 CLI**：

- `o1_` Key **自动本地解码**（移植了百炼官方的 Feistel + CRC32 算法，校验和不符会报错，所以解出来一定是对的）；
- 接口地址由 **Workspace + Region 自动拼接**：
  `https://<workspace>.<region>.maas.aliyuncs.com/compatible-mode/v1`
- 推荐模型：`qwen-plus` / `qwen-max` / `qwen-turbo` / `qwen3-max`

`config.json` 里长这样（Key 保持 `o1_` 原样即可，程序运行时再解码）：

```json
{
  "llm": {
    "provider": "bailian",
    "api_key": "o1_你的混淆Key",
    "workspace": "ws-xxxxxxxxxxxx",
    "region": "cn-beijing",
    "model": "qwen-plus"
  }
}
```

命令行等价写法：

```bash
python desktop_pet.py --set-llm-key "o1_你的混淆Key" --llm-provider bailian \
    --llm-workspace ws-xxxxxxxxxxxx --llm-region cn-beijing --llm-model qwen-plus
```

图形向导里选「阿里云百炼 Token Plan」，填 Key / Workspace / Region 即可（接口地址留空会自动拼）。

![百炼对话实测](screenshots/07_bailian_chat.png)

**人格联动**：发请求时会把宠物人设 + **当前四维数值和情绪**一起写进 system prompt，
所以接上模型后它会因为饿了而撒娇要吃的、困了而说话懒洋洋，而不是永远一个腔调。

**降级策略**：任何异常（超时 / 401 / 限流 / 断网）都会自动回落到本地规则回复，
并在控制台打印中文原因 —— 现场演示永远不会冷场。

## 七、常见问题

**Q：双击 `启动桌宠.bat` 没反应 / 窗口一闪就没了？**
A：新版启动器已经不会闪退（出错会 `pause` 并说明原因）。如果仍然异常，按顺序排查：
1. 双击 **`调试启动.bat`** —— 它会保留控制台并打印完整报错；
2. 看是不是 Python 没装好：命令行执行 `python -c "import sys"`，如果弹出微软应用商店，
   说明你 PATH 里第一个 `python` 是**假存根**，启动器会自动改用 `py -3`，也可以手动
   `py -3 desktop_pet.py`；
3. 看是不是依赖缺失：`pip install pillow`；
4. 确认 `assets/` 目录和 `desktop_pet.py` 在同一层。

**Q：双击 `启动桌宠.bat` 后显示「桌宠已退出」怎么办？**
A：**启动器现在会自动把「本次运行日志」打印在下面**，直接看那几行即可。日志长这样：

```
[时间][pid 12345][START]     argv=[] cwd=D:\黑客松 exe=... console=True
[时间][pid 12345][WINDOW]    hwnd=... pos=(1540,655) size=300x355
[时间][pid 12345][MAINLOOP]  进入 Tk 主循环
[时间][pid 12345][QUIT]      原因=右键菜单 / 调用栈: ...
[时间][pid 12345][EXIT]      正常退出
```
- 有 `QUIT` + `EXIT` → 是**被正常退出**了（菜单退出 / Alt+F4 / 窗口关闭消息），调用栈会指出是谁触发的；
- 只有 `MAINLOOP` 没有 `EXIT` → 进程是**被外部强制结束**的（任务管理器杀进程、控制台被关、杀软拦截）；
- 出现 `FATAL` / `CONSOLE-EVENT` → 分别是 **Python 异常** / **Ctrl+C 或控制台被关闭**；
- 出现 `Windows fatal exception: access violation` → 是**原生崩溃**，栈信息会指出崩在哪一行。

完整日志在 `logs/desktop_pet.log`，把它最后 20 行发我即可定位。

**Q：桌宠会不会自己突然消失？**
A：不会。已经移除了所有"容易被误触"的退出方式：**按 Esc 不再退出**（只会让它冒一句提示气泡），
唯一的正常退出方式是**右键宠物 → 退出**（或关闭它的控制台窗口）。所有退出路径都会记日志。

**Q：双击后桌宠出现但控制台黑窗口一直在？**
A：这是刻意设计——桌宠挂在控制台上运行，方便你随时看到状态机日志和退出原因
（关掉控制台即退出桌宠，一键收工）。不想要控制台就用命令行 `pythonw desktop_pet.py` 启动。

**Q：窗口是一片纯色/不透明？**
A：`-transparentcolor` 是 Windows 专属。请在 Windows 上运行；非 Windows 会打印警告但不会崩。

**Q：宠物不见了？**
A：可能走到屏幕外了。右键任务栏图标不适用（它不在任务栏里），直接重启程序即可；
或启动时用 `--pos 200,200` 指定位置。多显示器切换后也会自动跟随虚拟桌面范围。

**Q：打字时宠物老是抢我的输入焦点？**
A：不会。宠物窗口带 `WS_EX_NOACTIVATE`：点它、拖它都不会夺走键盘焦点，
启动瞬间也会把焦点还给原来的窗口。

**Q：提示找不到素材？**
A：把 `assets/` 目录和 `desktop_pet.py` 放在同一层。程序也会自动去脚本目录、桌面、
下载目录按原文件名（`OGC.gif` / `download.webp` / `6a024455af779H8Y.webp` / `OIP-C.webp`）搜索。

**Q：聊天没反应 / 一直是本地回复？**
A：运行 `python desktop_pet.py --llm-test "你好"` 看具体原因，常见是没配 Key 或 Key 欠费。
不配 Key 也能用，只是回复来自本地规则库。

**Q：启动很慢？**
A：首次启动要抠 116 帧动图（约 1.5 秒），之后走缓存 0.05 秒。清缓存删掉
`%TEMP%\desktop_pet_cache` 即可。

**Q：改宠物大小 / 速度 / 掉落速度？**
A：都在 `desktop_pet.py` 顶部的 `class CFG` 里，改完重启。

## 八、已知局限

1. 色键透明是**硬边**方案（alpha 只有 0/255），宠物边缘没有半透明羽化；要丝滑边缘需换 PySide6 的 `WA_TranslucentBackground`。
2. 色键要求像素颜色**精确**等于 `KEY_COLOR`，所以素材里不能出现 `#ff00fe`（可改配置换色）。
3. 气泡用 Tk Canvas 绘制，圆角是样条近似，没有抗锯齿。
4. 逻辑与渲染同线程（tkinter 单线程），只有素材解码和大模型请求在后台线程。
5. 抠图阈值按这 4 张素材调过（`PROFILES`），换新素材可能要微调。
